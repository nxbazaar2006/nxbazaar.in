# Performance, SEO, Accessibility and Images

Build currently fails on an external font fetch. SEO metadata is generic, language handling is incomplete, and several important image render paths use raw img tags. Form controls have labels, but error associations need accessibility hardening.

## Confirmed Defects

### NX-HIGH-007 - High - Production build

- Classification: Confirmed defects
- Evidence: Build failed: next/font/google could not fetch Inter from fonts.googleapis.com; app/layout.tsx lines 1 and 5 import/use Inter from next/font/google.
- File path: app/layout.tsx:1
- Description: Production build depends on network access to Google Fonts.
- Business impact: CI or deployment with restricted egress cannot produce a build artifact.
- Recommended solution: Self-host the font with next/font/local or remove external font dependency.
- Verification steps: Run next build with network disabled; build should pass.
- Estimated complexity: Small

### NX-MED-009 - Medium - SEO/metadata

- Classification: Confirmed defects
- Evidence: Lines 7-10 set title "Limi Ecommerce" and description "Generated by create next app"; line 14 hardcodes html lang="en" while app/[lang] routes exist.
- File path: app/layout.tsx:7
- Description: Global metadata and language do not match Nxbazaar.in or localized pages.
- Business impact: Poor search snippets, brand inconsistency and incorrect language semantics for Hindi/Marathi.
- Recommended solution: Set Nxbazaar.in metadata, add generateMetadata for product/category pages and localized html lang/alternate links.
- Verification steps: Rendered /, /hi and /mr HTML has correct title, description, lang and alternates.
- Estimated complexity: Medium

### NX-MED-010 - Medium - Image optimization

- Classification: Confirmed defects
- Evidence: Lines 52 and 69 use raw img tags with empty alt text; other raw img usage appears in BlogCard, blogs detail, Footer, RecentTrainings and OrderCard.
- File path: components/frontend/ProductImageCarousel.tsx:52
- Description: Key product/content images bypass next/image optimization and have weak alt text.
- Business impact: Slower LCP, poorer accessibility and less predictable image sizing.
- Recommended solution: Use next/image with stable dimensions/sizes and meaningful alt text for product/content images.
- Verification steps: Lighthouse image audits pass and product carousel images expose meaningful accessible names.
- Estimated complexity: Medium
